## 一、产品战略定位

### 一句话定位

> **妙不可园——以生活美学为核心品牌，以实用工具为引流引擎，打造"有用又有品"的个人数字空间。**

### 三层产品架构

```
妙不可园
│
├── 品牌核心层：六雅慢生活（茶·香·音·影·养·游）
│   ├── 定位：品牌灵魂，未来商业化主体
│   ├── 目标用户：追求生活品质的 25-40 岁人群
│   └── 价值：内容体验 + 生活工具 + 文化社区
│
├── 引流引擎层：实用工具模块
│   ├── 面试题库（901题）→ 吸引开发者群体
│   └── DNF 工具（礼包计算器/金币估算器）→ 吸引 30 岁左右游戏玩家
│   └── 价值：工具本身好用 → 用户自发分享 → 带来新用户 → 沉淀到六雅
│
└── 未来扩展层：待定
    ├── 可能方向：独立 App、电商导流、付费会员、线下体验
    └── 触发条件：六雅内容量 > 500 条 + 日活 > 1000 + 用户反馈集中
```

### 核心逻辑：工具引流 → 内容留存 → 品牌沉淀

```
用户路径：
DNF 玩家在群里看到分享的礼包计算器
  → 打开小程序使用计算器（觉得好用）
  → 用完后看到"妙不可园"的品牌和六雅内容
  → 好奇点击，发现茶品/香道内容不错
  → 收藏内容，成为留存用户

开发者搜到面试题库
  → 刷题时看到"妙不可园"的生活美学内容
  → 午休时打开看看养生/行旅内容
  → 从"工具用户"转化为"内容用户"
```

## 六、总结

**战略核心**：工具引流 → 内容留存 → 品牌沉淀

1. **六雅是品牌灵魂**：80% 精力投入，未来商业化的主体
2. **工具是获客引擎**：DNF 吸引玩家，面试题库吸引开发者，用完引导发现六雅
3. **三个模块都要发展**：六雅做深度，工具做精度，互相导流
4. **代码已具备上线条件**：24 项 Bug/优化已全部修复，7 个云函数已部署
5. **唯一阻塞项**：音乐音频缺失（不影响提审）+ 主包体积需优化（data 移入分包）
6. **未来可能成为 App**：当前在小程序打磨，Service 层已预留切换能力
