## 第 1 步：开通腾讯云 TTS 服务

> ⏱️ 约 3 分钟 | 网页操作

1. 浏览器访问 [腾讯云 TTS 语音合成控制台](https://console.cloud.tencent.com/tts)
2. 确认页面显示"已开通"。若未开通，点击"立即开通"（个人开发者每月 **500 万字符免费额度**）
3. 登录 [腾讯云 API 密钥管理](https://console.cloud.tencent.com/cam/capi)，获取：
   - **SecretId**：`<从腾讯云密钥管理复制，仅配置到云函数环境变量>`
   - **SecretKey**：*你自己保管的那串私钥*（切勿硬编码入代码仓库）
4. 确认授权策略为 `QcloudTTSFullAccess`

> ⚠️ 如提示需要实名认证，请先完成个人实名认证。

**✅ 判断成功**：页面能看到"已开通"字样或用量统计页面。

## 第 2 步：核对云环境 ID + 创建云数据库集合

> ⏱️ 约 5 分钟 | 微信开发者工具

### 2.1 核对云环境 ID
1. 微信开发者工具 → 点击顶部 **「云开发」** 按钮
2. 查看控制台左上角的 **环境 ID**
3. 打开 `miniapp/app.js` 第 125 行，确保 `env` 值与控制台环境 ID 一致：
   ```javascript
   wx.cloud.init({ env: '你的云开发环境ID', traceUser: true })
   ```

### 2.2 创建 9 个数据库集合
云开发控制台 → 左侧 **「数据库」** → 点 **「+」** 逐个创建：

| # | 集合名 | 用途 | 权限 |
|---|---|---|---|
| 1 | `users` | 用户资料 | 所有用户不可读写 |
| 2 | `sign_records` | 签到记录 | 所有用户不可读写 |
| 3 | `collections` | 收藏记录 | 所有用户不可读写 |
| 4 | `events` | 行为埋点 | 所有用户不可读写 |
| 5 | `history` | 浏览历史 | 所有用户不可读写 |
| 6 | `user_preferences` | 六雅偏好 | 所有用户不可读写 |
| 7 | `notification_settings` | 通知设置 | 所有用户不可读写 |
| 8 | `study_progress` | 学习进度、错题本与复习队列 | 所有用户不可读写 |
| 9 | `ugc_posts` | 用户投稿与公开社区内容 | 所有用户不可读写 |

**权限设置**：点击集合名 → 右上角 **「权限设置」** → 统一选择 **「所有用户不可读写」** → 保存。本项目客户端只调用云函数，云函数按 `_openid` 执行业务鉴权；不要给客户端直接读写数据库的权限。

### 2.3（推荐）创建数据库索引
- `users`：`idx_openid`，字段 `_openid`(ASC)
- `sign_records`：`idx_openid_date`，字段 `_openid`(ASC) + `date`(DESC)
- `collections`：`idx_openid_target`，字段 `_openid`(ASC) + `target_domain`(ASC) + `target_ref_id`(ASC)
- `collections`：`idx_openid_created`，字段 `_openid`(ASC) + `created_at`(DESC)
- `history`：`idx_openid_target`，字段 `_openid`(ASC) + `domain`(ASC) + `ref_id`(ASC)
- `history`：`idx_openid_visited`，字段 `_openid`(ASC) + `visited_at`(DESC)
- `user_preferences`、`notification_settings`、`study_progress`：分别创建 `_openid`(ASC) 单字段索引
- `ugc_posts`：`idx_openid_client`，字段 `_openid`(ASC) + `client_id`(ASC)
- `ugc_posts`：`idx_openid_created`，字段 `_openid`(ASC) + `created_at`(DESC)
- `ugc_posts`：`idx_public_created`，字段 `isPublic`(ASC) + `created_at`(DESC)
- `ugc_posts`：`idx_public_domain_created`，字段 `isPublic`(ASC) + `domain`(ASC) + `created_at`(DESC)

**✅ 判断成功**：左侧集合列表能看到上述 9 个集合，权限均不允许客户端直读写。

## 第 4 步：配置云函数环境变量与超时

> ⏱️ 约 3 分钟 | 云开发控制台

回到云开发控制台 → **「云函数」** → **「云函数列表」** 标签页。

### 4.1 配置 `tts` 云函数
1. 点击 `tts` 进入详情 → `$LATEST` 行右侧 **「配置」** 按钮
2. **环境变量** → 新增：
   - `TENCENT_SECRET_ID`：`<从腾讯云密钥管理复制，仅配置到云函数环境变量>`
   - `TENCENT_SECRET_KEY`：*你自己保管的 SecretKey*
3. **超时时间** → 改为 **10 秒** → 保存

### 4.2 配置 `getStudyData` 云函数
1. 返回列表 → 点击 `getStudyData` → **「配置」**
2. **环境变量** → 新增：
   - `STUDY_DATA_KEY`：`<使用密码管理器生成的随机密钥，不得写入仓库>`
   - `STUDY_DATA_URL`：`https://cdn.jsdelivr.net/gh/lijunpeng/workbuddy_project/data/study_data.enc`
   - *(备用直链：`https://gitee.com/LJunP/workbuddy-assets/raw/main/data/study_data.enc`)*
3. **超时时间** → 改为 **15 秒** → 保存（⚠️ 极重要，防止默认 3 秒超时报错）

**✅ 判断成功**：`tts` 和 `getStudyData` 的环境变量列表各显示 2 条记录。

## 第 5 步：配置隐私声明 + 域名白名单

> ⏱️ 约 10 分钟 | 微信公众平台 (mp.weixin.qq.com)

### 5.1 隐私保护指引
1. 登录 [微信公众平台](https://mp.weixin.qq.com)
2. **「设置」** → **「服务内容声明」** → **「用户隐私保护指引」** → 点击「去完善」
3. 勾选并填写用途：
   - **微信昵称头像** → `用于在个人中心及打卡记录中展示用户头像与昵称`
   - **选中的照片或视频信息** → `用于用户投稿时选择并上传配图`
   - **相册（写入）** → `用于保存生成的风雅卡片和海报图片到手机相册`
   - **设备信息** → `用于优化小程序页面适配及崩溃问题排查`
4. 在隐私说明中明确：用户选择“公开”时，投稿标题、正文和配图会展示给其他用户；私密投稿仅本人可见
5. 数据接收方、第三方处理方等内容必须按实际上线的数据流填写，不确定时不要填“无”；联系邮箱填你的邮箱
6. 勾选同意须知 → **「提交」**

### 5.2 服务器域名白名单
**「开发」** → **「开发管理」** → **「开发设置」** → **「服务器域名」**：
- **request 合法域名** + **downloadFile 合法域名** 添加：
  - `https://gitee.com`（CDN 图片与素材）
  - `https://cdn.jsdelivr.net`（加密题库拉取）

**✅ 判断成功**：提交后显示"提交成功，等待审核"（审核通常 1-2 小时内自动通过）。

## 第 10 步：常见报错排查 + 提审发布

### 常见问题

| 报错 | 原因 | 解决 |
|---|---|---|
| `getStudyData` timeout | 默认超时 3 秒 | 改为 **15 秒** |
| `tts` AuthFailure | 密钥配置有误 | 检查环境变量是否与 CAM 一致 |
| `Permission Denied` | 客户端误直连数据库，或云函数未部署到当前环境 | 本项目集合保持“所有用户不可读写”；检查调用是否经过云函数及环境 ID 是否一致 |
| 主包超过 2048KB | 本地图片过大 | 线上版本用 CDN 动态加载，移出大图 |

### 提审发布步骤

1. 微信开发者工具右上角 **「上传」**
2. 版本号 `1.0.0`，备注 `妙不可园正式上线版本`
3. [公众平台](https://mp.weixin.qq.com) → **「版本管理」** → **「开发版本」** → **「提交审核」**
4. 审核通过后 → **「发布」** → 全网上线
