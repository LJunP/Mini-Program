## 第 1 步：开通腾讯云 TTS 服务

> ⏱️ 约 3 分钟 | 网页操作

1. 浏览器访问 [腾讯云 TTS 语音合成控制台](https://console.cloud.tencent.com/tts)
2. 确认页面显示“已开通”，并检查当前账号仍有可用资源包或后付费额度；
   免费额度与计费规则以腾讯云控制台当日显示为准。
3. 登录 [腾讯云 API 密钥管理](https://console.cloud.tencent.com/cam/capi)，获取：
   - **SecretId**：`<从腾讯云密钥管理复制，仅配置到云函数环境变量>`
   - **SecretKey**：*你自己保管的那串私钥*（切勿硬编码入代码仓库）
4. 确认授权策略为 `QcloudTTSFullAccess`

> ⚠️ 如提示需要实名认证，请先完成个人实名认证。
>
> 已配置并通过真实 TTS 调用的环境不要重复创建、复制或轮换密钥。只有环境变量缺失、

| # | 集合名 | 用途 | 权限 |
|---|---|---|---|

| 2 | `sign_records` | 签到记录 | 所有用户不可读写 |
| 3 | `collections` | 收藏记录 | 所有用户不可读写 |
| 4 | `events` | 行为埋点 | 所有用户不可读写 |
| 5 | `history` | 浏览历史 | 所有用户不可读写 |
| 6 | `user_preferences` | 六雅偏好 | 所有用户不可读写 |
| 7 | `notification_settings` | 通知设置 | 所有用户不可读写 |

### 2.3 创建数据库索引
- `users`：`idx_openid`，字段 `_openid`(ASC)
- `sign_records`：`idx_openid_date`，字段 `_openid`(ASC) + `date`(DESC)
- `collections`：`idx_openid_target`，字段 `_openid`(ASC) + `target_domain`(ASC) + `target_ref_id`(ASC)
- `collections`：`idx_openid_created`，字段 `_openid`(ASC) + `created_at`(DESC)
- `history`：`idx_openid_target`，字段 `_openid`(ASC) + `domain`(ASC) + `ref_id`(ASC)
- `history`：`idx_openid_visited`，字段 `_openid`(ASC) + `visited_at`(DESC)
- `user_preferences`、`notification_settings`、`study_progress`：分别创建 `_openid`(ASC) 单字段索引
- `ugc_posts`：`idx_openid_client`，字段 `_openid`(ASC) + `client_id`(ASC)
- `ugc_posts`：`idx_openid_created`，字段 `_openid`(ASC) + `created_at`(DESC)
- `ugc_posts`：`idx_openid_domain_created`，字段 `_openid`(ASC) + `domain`(ASC) + `created_at`(DESC)
- `ugc_posts`：`idx_public_status_created`，字段 `isPublic`(ASC) + `status`(ASC) + `created_at`(DESC)
- `ugc_posts`：`idx_public_status_domain_created`，字段 `isPublic`(ASC) + `status`(ASC) + `domain`(ASC) + `created_at`(DESC)
- `ugc_posts`：`idx_status_created`，字段 `status`(ASC) + `created_at`(ASC)，供人工审核按提交时间处理
- `ugc_posts`：`idx_status_updated`，字段 `status`(ASC) + `updated_at`(ASC)，供删除积压巡检

> `idx_openid_client` 必须在历史数据迁移完成后设置为唯一复合索引，以防并发重复投稿。
> 顺序固定为：导出备份 → 为缺失 `client_id` 的历史记录制定并记录回填值
> （可沿用文档 `_id`）→ 按 `_openid + client_id` 查出空值和重复对并逐条处置
> → 确认无冲突后创建唯一索引 → 用重复写入测试确认约束生效。不得盲合并、盲删旧记录。

新版 `login` 和 `sign` 分别以 OPENID、`OPENID + 北京日期` 的 SHA-256 摘要生成
确定性文档 ID，并使用原子新增处理并发。部署前仍须导出并审计历史数据：

1. 查询同一 `_openid` 对应多个 `users` 文档的情况；确定保留/合并规则前不得盲删。
2. 查询同一 `_openid + date` 对应多个 `sign_records` 文档的情况；核对积分记录后
   再处置，不能仅按文档数量扣减用户积分。
3. 部署后在测试账号上并发调用，确认新账号只产生一个 `users` 文档，同日只产生一个
   `sign_records` 文档，重复签到返回 `alreadySigned=true` 且不重复增加积分。

**✅ 判断成功**：左侧集合列表能看到上述 9 个集合，权限均不允许客户端直读写。

### 2.4 迁移历史 UGC 数据

部署新版 `ugc` 前，先导出 `ugc_posts` 备份并记录文档总数，然后按以下规则迁移：

1. 已有 `status: "deleted"` 的最小删除墓碑必须保留，禁止改回 `private`
   或物理删除；它用于压制其他设备遗留的离线副本。
2. 已有 `status: "deleting"` 的记录先进入清理异常清单，不参与普通状态迁移。
3. 其余 `isPublic !== true` 的活动记录设为 `status: "private"`。
4. `isPublic === true` 且缺少有效审核状态的活动记录设为 `status: "pending"`；
   禁止将历史公开稿批量设为 `approved`。
5. 按记录的 `_openid` 查询 `users`，用服务端用户资料中的 `nickname`
   回填活动投稿的 `authorName`；旧版客户端提交的作者名不能直接视为可信。
   `deleted` 墓碑不重新填充业务或展示字段。
6. 新版投稿图片路径应为 `ugc/<users._id>/...`。不符合该路径的历史图片只标记为
   人工核验，不得由脚本盲删。
7. 统计所有非 `deleted/deleting` 活动记录的 `updated_at`。缺失、空值或非法值必须
   在备份后回填可审计的迁移基线时间；如果存在可信旧修改时间则保留。逐条记录原值、
   新值和执行时间。未完成前禁止开放投稿写入或执行并发验收。
8. 保存迁移前导出、迁移数量、异常清单和执行人记录。

UGC 状态含义：

| 状态 | 含义 | 客户端/社区行为 |
|---|---|---|
| `private` | 私密投稿 | 仅作者可见 |
| `pending` | 等待人工审核 | 仅作者可见 |
| `approved` | 人工审核通过 | `isPublic=true` 时可公开 |
| `rejected` | 人工审核拒绝 | 仅作者可见 |
| `deleting` | 文件或数据库清理处理中 | 停止公开，保留重试数据 |
| `deleted` | 清理成功后的最小删除墓碑 | 客户端过滤、详情拒绝，用于防止离线副本复活 |

详细执行规程见
[`UGC内容审核与清理操作规程.md`](./UGC内容审核与清理操作规程.md)。

### 4.3 配置 `getStudyData` 云函数

   `study/study_data.json`，无需把题库发布到公共 CDN，也无需重复覆盖现有密钥。
3. 只有需要切换数据源时才新增或修改：
   - `STUDY_DATA_FILE_ID`：`<当前环境内私有 JSON 或 study_data.enc 的完整 cloud:// File ID>`
   - `STUDY_DATA_KEY`：`<仅当 File ID 指向 study_data.enc 时需要>`
   - `STUDY_DATA_URL`：`<仅在不使用私有云存储时作为 HTTPS 备选地址>`
4. **超时时间** → 改为 **15 秒** → 保存（⚠️ 极重要，防止默认 3 秒超时报错）

> 当前已配置的 `STUDY_DATA_URL` 即使保留也不会覆盖默认私有文件；
> 若未来主动切回 HTTPS 备选源，录入前必须确认直链返回 HTTP 200。

## 第 5 步：配置隐私声明 + 域名白名单

> ⏱️ 约 10 分钟 | 微信公众平台 (mp.weixin.qq.com)

### 5.1 隐私保护指引

> 以下内容已根据 2026-07-25 实际代码审查结果更新，覆盖当前小程序真实调用的全部用户数据和权限。

1. 登录 [微信公众平台](https://mp.weixin.qq.com)
2. **「设置」** → **「服务内容声明」** → **「用户隐私保护指引」** → 点击「去完善」
3. 勾选并填写用途（基于代码审查的实际调用）：

   | 隐私信息类型 | 用途填写建议 | 代码来源 |
   |---|---|---|
   | **微信昵称头像** | 用于在个人中心、签到记录和公开投稿中展示用户头像与昵称 | `cloudfunctions/login`、`cloudfunctions/updateProfile`、`pages/profile`、`pages/edit-profile` |
   | **选中的照片或视频信息** | 用于用户投稿时从相册或相机选择并上传配图 | `pages/contribute/contribute.js` → `wx.chooseMedia`（sourceType: album, camera） |
   | **相册（写入）** | 用于将生成的风雅海报、茶品卡片和工具计算结果保存到手机相册 | `content-detail.js`、`tea-detail.js`、`dnf-summer-2026/calculator.js` → `wx.saveImageToPhotosAlbum` |
   | **设备信息** | 用于页面适配、窗口布局计算和崩溃/内存问题排查 | `app.js` → `wx.getDeviceInfo()`、`wx.getWindowInfo()` |

4. 在隐私说明正文中还需明确：
   - 用户投稿默认为私密，仅本人可见；用户主动选择“公开”后先进入人工审核，
     只有 `status=approved` 的投稿才会进入社区 Feed
   - 用户可随时将已公开的投稿改回私密；已审核公开稿修改内容后会重新进入待审核状态
   - 用户浏览记录、收藏、签到、学习进度等数据通过微信云开发存储在腾讯云服务器
   - 订阅消息（签到提醒、内容更新提醒等）需用户主动授权，用户可随时在微信设置中关闭
   - 卸载小程序不会自动删除云端数据；单条投稿删除失败时可能进入待清理状态
5. **数据接收方与第三方处理方**：
   - 用户数据存储和处理方：微信云开发（腾讯云），提供数据库和云函数服务
   - 语音合成服务方：腾讯云 TTS（仅处理面试题文本内容，不接触用户个人身份信息）
   - 不确定的内容不要填"无"；联系邮箱填你的真实邮箱
6. 勾选同意须知 → **「提交」**

> ⚠️ 注意：订阅消息模板 ID 已在 `utils/subscribe-config.js` 中配置（4 个模板），但模板是否已在公众平台实际申请并投递成功仍需验证。提交隐私指引前请确认订阅消息配置与实际投递状态一致。
>
> ⚠️ 当前小程序只引导用户使用微信“反馈与投诉”，隐私页没有展示已经过运营主体
> 核验的邮箱或客服渠道。提交前必须由运营主体提供并验证一个能处理访问、更正、

## 第 10 步：常见报错排查 + 提审发布

### 常见问题

| 报错 | 原因 | 解决 |
|---|---|---|
| `getStudyData` timeout | 默认超时 3 秒 | 改为 **15 秒** |
| `tts` AuthFailure | 密钥配置有误 | 检查环境变量是否与 CAM 一致 |
| `Permission Denied` | 客户端误直连数据库，或云函数未部署到当前环境 | 本项目集合保持“所有用户不可读写”；检查调用是否经过云函数及环境 ID 是否一致 |
| 主包超过 2048KB | 本地图片仍被打包，或忽略规则未生效 | 检查 `project.config.json` 已忽略 `assets/images`，并确认图片已上传到 `app-assets/images` |
| `STORAGE_FILE_NONEXIST` | 云端图片缺失或相对路径不一致 | 对照本地 `assets/images` 补传到 CloudBase `app-assets/images` 的同名路径 |
| `STORAGE_EXCEED_AUTHORITY` | 客户端直接读取私有存储，或 `getStudyData` 仍是旧版本 | 重新部署 `getStudyData`；图片临时地址必须由该云函数签发，不要放开存储桶 |
| 腾讯云主控制台显示“上海 0 个环境”或 CloudBase 未激活 | 当前查看的是未绑定本小程序微信环境的腾讯云主账号/地域 | 不在该页面创建替代环境；回到微信开发者工具的「云开发」入口核对真实环境 |
| `getCloudAPISignedHeader` / `41002` | 腾讯云网页已登录，但微信开发者工具的账号、项目或云函数发布授权失效 | 在微信开发者工具内刷新登录，必要时退出后重新扫码；不要重复配置 TTS 密钥，也不要在腾讯云主控制台新建替代环境 |
| UGC 响应缺少或不匹配 `server_build` | `ugc` 未部署、部署到了错误环境或仍在运行旧版本 | 在微信开发者工具对应环境重新部署，并再次调用 `getMyPosts` |
