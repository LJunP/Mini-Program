# 妙不可园 · 产品方案

> **更新日期**：2026年7月24日

## 一句话定位

妙不可园是一个把“慢生活内容”和“长期学习”放在同一个小程序里的双模式内容产品。

- 休闲模式：用香、音、茶、影、养、游六雅帮助用户慢下来。
- 学习模式：用教程、知识、面试题库、复习队列帮助用户持续积累。

产品气质不是信息流短视频式消耗，而是“可收藏、可复习、可长期使用”的内容资产库。

## 核心用户

| 用户 | 需求 | 产品承接 |
|---|---|---|
| 倦怠打工人 | 想慢下来，但不想刷无意义内容 | 六雅内容、每日推荐、书签 |
| 慢生活用户 | 想建立有审美的生活方式 | 茶、香、音、影、养、游内容库 |
| 技术学习者 | 想系统化补知识和面试题 | 学习模式、题库、复习队列 |
| 准备面试者 | 想高频、真实、结构化的题库 | 18 个专题、完整 901 道面试题（本地精简版 90 道） |
| 内容沉淀型用户 | 想收藏、回看、复习 | 书签、历史、进度 |

## 休闲模式设计

### 六雅板块

| 板块 | domain | 当前内容 | 角色 |
|---|---|---:|---|
| 茶 | `tea` | 60 款 | 品鉴与知识入口 |
| 游 | `travel` | 6 个专题 | 串联六雅的场景容器 |
| 养 | `wellness` | 14 篇 | 日常调理与生活习惯 |
| 香 | `incense` | 12 篇 | 静心与仪式感 |
| 音 | `music` | 12 篇 | 古曲与氛围陪伴 |
| 影 | `film` | 12 篇 | 文艺电影与精神滋养 |

### 内容关系

游是“场景容器”，其他五雅是“内容节点”。

```text
travel
  -> linkedDomains[]
    -> tea / wellness / incense / music / film
```

示例：

```js
{
  domain: 'travel',
  id: 'travel_001',
  linkedDomains: [
    { domain: 'tea', refId: 'tea_021', context: '武夷岩茶体验' },
    { domain: 'wellness', refId: 'wellness_004', context: '山居作息' },
    { domain: 'film', refId: 'film_002', context: '夜间观影' }
  ]
}
```

## 用户资产设计

用户资产分为四类：

```text
收藏资产：collection
行为资产：history / tracker
偏好资产：preferences / persona
学习资产：study-progress
```

当前实现以本地 Storage 为主，已部署 7 个云函数（login/collection/sign/updateProfile/tts/track/getStudyData）实现核心资产云端同步。未来接完整后端后可平滑切换。

## 产品原则

1. 不做碎片化消耗，做长期可回看的内容资产。
2. 页面只负责交互，数据来源统一走服务层。
3. 休闲内容重审美，学习内容重准确。
4. 收藏、历史、复习都必须能沉淀用户资产。
5. 后端接入不应重写页面，只替换服务实现。
