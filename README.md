# 妙不可园小程序（风雅生活 & 学习双模式系统）

妙不可园（风雅生活）小程序是一个采用原生微信小程序技术栈开发的生活美学内容与学习管理系统。
当前版本已完成从单一的“茶文化”内容社区到“六雅日常修行 + 长期学习模式”的双模式闭环系统的全面升级。

---

## 🚀 快速开始

### 1. 运行环境要求
* 微信开发者工具（建议最新稳定版）
* 基础库版本：`3.0.0` 或以上

### 2. 导入与运行步骤
1. 打开 **微信开发者工具**。
2. 选择 **导入项目**，将项目指向本地工作目录下的 `miniapp/`。
3. AppID 可使用**测试号**或您个人的 AppID。
4. 当前默认开启 **Mock 数据模式**，无需额外配置或启动任何后端 API 服务，导入即可全量预览。

## 🎨 核心功能模式

### 1. 休闲模式 (Leisure Mode) —— 风雅生活修行
致力于给慢下来的人提供风雅生活指南，包含以下板块：
* **香 (incense)**：线香香薰品鉴，修心减压。
* **音 (music)**：国风白噪音、古琴，怡情安神。
* **茶 (tea)**：六大茶类百科，详细口感画像（雷达图）与冲泡指引。
* **影 (film)**：治愈系人文电影与纪录片推荐。
* **养 (wellness)**：轻量化、不焦虑的节气及部位调理指南。
* **游 (travel)**：人文深度游专题，作为“容器”通过跨板块关联机制融合其余五雅。

### 2. 学习模式 (Study Mode) —— 专业知识积累
面向专业和技术积累，包含以下模块：
* **教程 (tutorials)**：开发工具、工程化指南。
* **知识 (knowledge)**：技术史与人物志。
* **面试 (interview)**：包含 18 个技术专题，本地精简版 **90 道**（每专题5题），完整数据集 **901 道**（存放在 `data/study_data.json` 供云端部署）。
* **复习 (review)**：基于本地学习进度的智能复习队列。

## 🏗️ 核心技术决策与设计思想

### 1. 数据获取隔离 (Mock 切换边界)
页面不直接依赖底层数据结构，所有数据请求均由 `services/*` 派发。
网络底座 `utils/request.js` 通过 `utils/config.js` 的 `enableMock` 控制数据重定向。
* 当 `enableMock: true`：直接交由 `utils/mock.js` 在本地 `utils/data-store.js` 及 `data/study/` 中过滤与计算，实现**零后端开销运行**。
* 当 `enableMock: false`：通过常规的 HTTP 请求与真实后端 API 对接，方便未来平滑升级。

### 2. 轻量级状态管理 (`store/index.js`)
项目没有使用像 MobX 或 Redux 这样笨重的小程序第三方包，而是利用原生的 **订阅/发布 (Subscribe/Notify) 模式** 建立了一个超轻量的数据中心。
页面只需在 `onLoad` 中 `store.subscribe((state) => { ... })` 即可获取全局的用户登录态、偏好设置、收藏夹数量和风雅画像变动。

### 3. 本地高级搜索引擎 (`utils/search-engine.js`)
为在纯 Mock 状态下提供极佳的交互体验，手写了高效的本地模糊搜索模块：
* 支持 **拼音首字母与全拼搜索**（利用本地 pinyin 字典）。
* 实现了 **多字段加权打分机制**（例如在茶品搜索中，名称匹配权重为 2.0，产地为 1.5，冲泡属性为 0.6）。
* 支持**空格分词**与多关键词联合搜索。

## 🌍 环境切换与配置

在 `miniapp/utils/config.js` 中定义了三个核心环境：
* **development** (开发环境)：`enableMock = true`，使用本地内联数据和相对路径图片。
* **staging** (测试环境)：`enableMock = false`，对接 `staging-api.halfday.com`。
* **production** (生产环境)：`enableMock = false`，对接生产级 API 与 CDN。
