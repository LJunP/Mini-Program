## 文档说明

### 产品文档 (`product/`)
- **风雅生活小程序产品方案-六雅升级版.md**：核心产品规划文档，定义了六雅（香、音、茶、影、养、游）休闲模式与学习模式的双模式产品形态。

### 技术文档 (`technical/`)
- **API接口文档.md**：后端 API 目标协议设计，包含鉴权、内容、搜索、收藏、学习、埋点等全部接口定义。
- **数据库设计文档.md**：关系型数据库表结构设计，支持从本地 Mock 平滑迁移到云端。
- **TECH_STATUS.md**：技术实现与产品方案的对齐状态报告，记录各模块完成度和已知技术债。

### 工具参考 (`tools/`)
- **DNF-2026夏日礼包...md**：DNF 夏日礼包计算器小程序功能的数据参考文档，用于 `miniapp/subpackages/tools/pages/dnf-summer-2026/` 计算器的数据建模。

### 资源文档 (`assets/`)
- **all-missing-images-prompts.md**：小程序图片资源治理期间使用的 AI 图片生成提示词清单，记录了所有缺失封面图的具体生成方案。
