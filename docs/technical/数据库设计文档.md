# 妙不可园数据库设计文档

本文档描述未来后端数据库目标结构。当前小程序仍以本地内联数据运行，但数据形态已经可以映射到以下表结构。

---

## 1. 设计原则

1. 六雅内容统一建模。
2. 收藏、点评、历史、学习进度使用多态目标引用。
3. 面试题库独立成学习域，不混入休闲内容表。
4. 支持从本地 Mock 数据平滑迁移到云端数据库。
5. 页面不直接依赖表结构，只依赖服务层 DTO。

## 4. 用户表

```sql
CREATE TABLE users (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  openid VARCHAR(64) NOT NULL,
  unionid VARCHAR(64) DEFAULT NULL,
  nickname VARCHAR(64) DEFAULT NULL,
  avatar_url VARCHAR(512) DEFAULT NULL,
  status VARCHAR(16) NOT NULL DEFAULT 'active',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_openid (openid),
  KEY idx_unionid (unionid)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 5. 六雅内容表

### 5.1 通用内容 `contents`

用于养生、香道、音乐、电影等“内容即实体”的板块。

```sql
CREATE TABLE contents (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  content_no VARCHAR(64) NOT NULL,
  domain VARCHAR(32) NOT NULL,
  title VARCHAR(160) NOT NULL,
  summary VARCHAR(512) DEFAULT NULL,
  cover_image VARCHAR(512) DEFAULT NULL,
  category VARCHAR(64) DEFAULT NULL,
  difficulty TINYINT DEFAULT 1,
  duration VARCHAR(64) DEFAULT NULL,
  body MEDIUMTEXT DEFAULT NULL,
  tips JSON DEFAULT NULL,
  tags JSON DEFAULT NULL,
  extra JSON DEFAULT NULL,
  status VARCHAR(16) NOT NULL DEFAULT 'published',
  sort INT NOT NULL DEFAULT 0,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_content_no (content_no),
  KEY idx_domain_category (domain, category),
  KEY idx_status_sort (status, sort)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 6. 跨板块关联表

```sql
CREATE TABLE content_links (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  source_domain VARCHAR(32) NOT NULL,
  source_ref_id VARCHAR(64) NOT NULL,
  target_domain VARCHAR(32) NOT NULL,
  target_ref_id VARCHAR(64) NOT NULL,
  context VARCHAR(255) DEFAULT NULL,
  sort INT NOT NULL DEFAULT 0,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_source (source_domain, source_ref_id),
  KEY idx_target (target_domain, target_ref_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

示例：

```text
travel_001 -> tea_021
travel_001 -> wellness_004
tea_021    <- travel_001
```

## 8. 用户资产表

### 8.1 收藏 `collections`

```sql
CREATE TABLE collections (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  target_domain VARCHAR(32) NOT NULL,
  target_ref_id VARCHAR(64) NOT NULL,
  note VARCHAR(255) DEFAULT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_user_target (user_id, target_domain, target_ref_id),
  KEY idx_user_created (user_id, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 8.2 浏览历史 `browse_history`

```sql
CREATE TABLE browse_history (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  target_domain VARCHAR(32) NOT NULL,
  target_ref_id VARCHAR(64) NOT NULL,
  title VARCHAR(200) DEFAULT NULL,
  last_viewed_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  view_count INT NOT NULL DEFAULT 1,
  UNIQUE KEY uk_user_target (user_id, target_domain, target_ref_id),
  KEY idx_user_time (user_id, last_viewed_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 8.3 学习进度 `study_progress`

```sql
CREATE TABLE study_progress (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  item_domain VARCHAR(32) NOT NULL,
  item_ref_id VARCHAR(64) NOT NULL,
  status VARCHAR(32) NOT NULL DEFAULT 'new',
  mastery TINYINT NOT NULL DEFAULT 0,
  review_count INT NOT NULL DEFAULT 0,
  next_review_at DATETIME DEFAULT NULL,
  last_reviewed_at DATETIME DEFAULT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_user_item (user_id, item_domain, item_ref_id),
  KEY idx_next_review (user_id, next_review_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 8.4 用户画像 `user_persona`

```sql
CREATE TABLE user_persona (
```

## 9. 埋点表

```sql
CREATE TABLE user_events (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT DEFAULT NULL,
  anonymous_id VARCHAR(64) DEFAULT NULL,
  event_name VARCHAR(64) NOT NULL,
  page_path VARCHAR(255) DEFAULT NULL,
  target_domain VARCHAR(32) DEFAULT NULL,

  KEY idx_event_time (event_name, server_time),
  KEY idx_target (target_domain, target_ref_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 10. 迁移优先级

1. `users`、登录与 token。
2. `tea_items`、`travel_topics`、`contents`。
3. `collections`、`browse_history`。
4. `interview_questions`、`study_progress`（完整题库已在 `data/study_data.json` 中就绪）。
5. `user_events`、`user_persona`。
6. CMS 后台表和审核流。

> **注**：完整学习数据集（18 篇教程、18 篇知识、901 道面试题）已打包为 `data/study_data.json`，可直接导入云开发数据库。本地精简版每专题仅保留5题以控制包体积。
